# eval

| 文件 | 作用 |
|---|---|
| `eval_checkpoint.py` | 在评测基准上跑 n 次采样，按测试通过比例打分，保存逐题数据 |
| `paired_test.py` | 两个 checkpoint 的配对 bootstrap 检验（10000 次） |
| `test_code_reward.py` | 奖励函数单测，18 个用例，不需要 GPU |

## 为什么用配对检验

同一批题、同一口径下逐题配对，能消掉题目难度方差。
比看两个总体均值的差灵敏得多，也不需要更大的题量。

报告形式：配对差 + 95% CI + 变好/变坏/不变题数 + 单侧 p。

## 为什么用多次采样的 pass rate 而非二元 pass@1

| 口径 | MDE（326 题） |
|---|---|
| 二元 pass@1 | 6.9pp |
| pass rate（8 采样） | **2.4pp** |

同样 326 题，等价于把题量放大 8 倍。对比 MATH-500 的 5.6pp、AIME 的 22.9pp。

## 已得结果

| 对比 | 配对差 | 95% CI | p |
|---|---|---|---|
| step12 vs base | +0.91pp | [-0.27, +2.09] | 0.067 |
| step6 vs base | +0.64pp | [-0.60, +1.87] | 0.155 |
| step6 vs step12 | +0.27pp | [-0.84, +1.37] | 0.306 |

三个 CI 全部含 0。**不能**声称训练有效。
