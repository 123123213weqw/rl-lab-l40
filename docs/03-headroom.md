# Prompt / 奖励是不是太简单：实测可学空间

日期：2026-10-26。模型：Qwen3-8B（训练前）。方法：每个 prompt 采样 8 次，测 pass rate。

## 结论

不是「奖励太简单」，是**三件不同的病**，而且主因是**任务已饱和**。

## 实测数据（250 个 GSM8K 测试题 × 8 次采样）

整体准确率 **93.45%**。

```
每 prompt 对了几个（共 8 个样本）
  0/8 :   6 个 ( 2.4%)
  1/8 :   3 个 ( 1.2%)
  2/8 :   3 个 ( 1.2%)
  3/8 :   2 个 ( 0.8%)
  4/8 :   1 个 ( 0.4%)
  5/8 :   2 个 ( 0.8%)
  6/8 :   6 个 ( 2.4%)
  7/8 :  12 个 ( 4.8%)
  8/8 : 215 个 (86.0%)   ← 完全饱和
```

- 全对 **86.0%**，全错 2.4%，**有分化只有 11.6%**
- pass_rate ∈ [0.25, 0.75]（最理想的学习区）只有 **5.6%**

## GRPO 有效组比例

零方差组的概率 = p^G + (1-p)^G，按实测每个 prompt 的 p 逐个算再平均：

| G | 零方差组 | 有效组 |
|---|---|---|
| 2 | 79.7% | 20.3% |
| **4（当前）** | **61.7%** | **38.3%** |
| 8 | 39.3% | 60.7% |
| 16 | 16.6% | 83.4% |
| 32 | 3.0% | 97.0% |
| 64 | 0.1% | 99.9% |

**G=4 时有 61.7% 的算力在算零梯度。**

（补充：实际训练第 10 步那一批 32 个 prompt 观测到 27/32 = 84.4% 零方差，
比这个 61.7% 更高——单批样本偏简单。两个数方向一致。）

## 难度分化程度

iid 假设下用整体均值 p=0.848 预测，G=4 零方差应为 51.7%；
实测分布是 61.7%。**高出 10 个百分点**说明难度不是均匀分布，
而是堆在两端（要么总对、要么总错），中间可学的更少。

## 按难度过滤的收益

过滤到 pass_rate ∈ [0.1, 0.9]：

- 只保留 **29/250 = 11.6%** 的 prompt
- G=4：零方差 61.7% → **31.5%**，有效组 38.3% → **68.5%**
- G=8：有效组 → **89.3%**

**过滤比提 G 便宜**：同样到 ~68% 有效组，过滤不额外花算力，
而 G=16 要 4 倍算力。

## 代价：题目池会不够

GSM8K train 6,961 条 × 11.6% ≈ **807 条**可用。
按 batch 32 算，**一个 epoch 只有 25 步**就要重复。

所以过滤必须配合**扩充题目池**——这是「换更难数据」的真正驱动力，
不只是为了更难。

## 三件病，分开修

| # | 病 | 证据 | 修法 | 成本 |
|---|---|---|---|---|
| 1 | **任务饱和**（主因） | 86% 的题 8/8 全对 | 难度过滤 + 扩充题库 | 一次离线采样 |
| 2 | **奖励把格式和正确性耦合** | 格式违规直接 0 分；正则能替代 98.8% 的增益 | 拆开：正确性为主，格式给极小权重或归一化后再判 | 改 reward.py |
| 3 | **prompt 在替奖励干活** | prompt 里规定 `#### N`，只因评分器解析不了自由格式 | 让评分器健壮解析，格式不必用 RL 教 | 改评分器 |

注意 #2 不是「奖励太简单」，是**错位**。二元可验证奖励本身是对的、
抗 hack 的；问题是不该让格式当门控。

## 明确反对的做法

**不要因为这个结论就上 PRM / 过程奖励模型。**
- 当前 p=0.93、G=4、61.7% 零方差——问题在「没题可学」，不在「信号不够细」
- PRM 引入奖励 hack 风险，且需要额外训练一个打分模型
- 先做 #1 和 #2，如果过滤后有效组到 68% 仍在平台期，再考虑 PRM

## 真正的结构性修法

GSM8K 对 8B 在 2026 年已经饱和。要拿到真实推理增益必须换到有 headroom 的可验证任务：

- **代码**（HumanEval+ / MBPP+ / LiveCodeBench）：单测可验证、pass rate 低、
  信号比二元对错更细（通过 k/n 个测试），且难以 hack
- **更难数学**（MATH level 4-5 / AIME / OlympiadBench）
- 注意：太难也不行——p→0 时 (1-p)^G→1，同样零方差。
  必须做难度分层 + 每层单独过滤，不是「直接上最难的」
